# 용어집

용어가 **처음 나오는 단계**에서 아래 정의로 한 문장 풀어준다. 학습자 배경에 맞는 비유를 덧붙여도 된다.
그 단계 전에는 쓰지 않는다. 한 번 설명한 뒤에는 같은 이름으로만 부른다.

## 등장인물 (3단계에서 한 번 그림으로 소개)

| 이름 | 처음 나오는 단계 | 한 문장 정의 |
|---|---|---|
| 학습자 | 0 | 지금 이 학습을 하는 사람. 질문하고, 입력하고, 화면을 본다 |
| Claude Code | 0 | 학습자 컴퓨터에서 도는 AI 앱. MCP 서버를 실행하고 연결해서 쓴다. (스펙 용어로는 "호스트") |
| MCP 서버 | 0 | AI 앱에 기능과 데이터를 주는 프로그램. 오늘은 `server/server.py` |
| 모델 | 3 | 원격에서 텍스트를 주고받는 AI(Claude). 학습자 컴퓨터에 직접 손대지 않는다 |

MCP 클라이언트는 등장인물로 따로 소개하지 않는다. 필요할 때만 "Claude Code 안에서 MCP 서버와 연결을 맡는 부분"이라고 설명한다.

## 개념

| 용어 | 처음 나오는 단계 | 한 문장 정의 |
|---|---|---|
| MCP | 0 | AI 앱이 외부 프로그램의 기능과 데이터를 쓸 수 있게 해주는 약속(프로토콜) |
| Tool | 1 | 모델이 대화 중에 스스로 판단해서 부르는 함수 |
| Resource | 1 | 주소(URI)로 찾아 읽는 데이터. 학습자가 첨부하거나, AI 앱이 허용하면 모델이 읽는다 |
| Prompt | 1 | 학습자가 메뉴에서 골라 쓰는 질문 템플릿 |
| 입력 스키마 | 1 | 도구가 받는 인자의 이름과 타입. 파이썬 타입 힌트에서 자동으로 만들어진다 |
| calls.log | 1 | MCP 서버가 호출될 때마다 한 줄씩 남기는 기록. 이 학습의 관찰 도구 |
| 스펙 | 1 | MCP의 공식 규칙 문서. https://modelcontextprotocol.io/specification/2026-07-28 |
| stdio | 2 | 표준 입출력. Claude Code가 MCP 서버를 프로그램으로 실행하고, 입력과 출력으로 대화하는 방식 |
| 자식 프로세스 | 2 | Claude Code가 실행한 MCP 서버 프로그램. Claude Code 세션이 끝나면 같이 종료된다 |
