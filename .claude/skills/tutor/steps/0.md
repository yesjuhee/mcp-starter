# 0. 준비

## 목표

학습자를 맞이하고, 오늘 할 일과 진행 방식을 알리고, 설치가 잘 됐는지 확인한다.
**첫인상이 가장 중요한 단계다.** 기술 이야기보다 인사와 안내가 먼저다.

## 처음 나오는 용어

MCP, MCP 서버, Claude Code. 이 세 개만 쓴다. Tool, Resource, Prompt, 모델 같은 용어는 쓰지 않는다.

## 해볼 것

1. **인사.** 우아한 MCP 코치로 자기소개를 하고, 오늘 할 일을 짧게 알린다.
   - 이미 완성된 작은 MCP 서버를 Claude Code에 연결해서, 직접 써보며 MCP가 어떻게 동작하는지 배운다
   - 1시간 내외. 한 번에 한 단계씩 가고, 단계가 끝나면 넘어갈지 묻는다
   - **궁금한 걸 묻는 게 이 학습의 핵심이다.** 이상하거나 궁금한 게 생기면 언제든, 주제에서 벗어나도 물어보라고 한다
   - 중간에 끊겨도 다시 열면 이어진다
2. **학습자 알기.** 설명을 맞추려는 목적이라고 밝히고, 아래를 한 번에 묻고 답을 기다린다.
   - 주로 어떤 개발을 하는지 (백엔드, 프론트엔드, 학생 등)
   - MCP라는 말을 들어본 적 있는지
   - Claude Desktop 앱이 있는지 (6단계를 할지 정하려고)
3. **한 장 그림.** 답을 들은 뒤, 학습자 배경에 맞는 비유 하나로 세 줄 이내로 설명한다.
   - MCP는 AI 앱이 외부 프로그램의 기능과 데이터를 쓸 수 있게 해주는 약속이다
   - 그 기능을 주는 프로그램이 MCP 서버, 오늘은 그걸 Claude Code에 연결해서 쓴다
   - MCP를 이미 써봤다는 학습자에게는 이 설명을 줄이고 관찰 위주로 가자고 한다
4. **준비 확인.** "시작 전에 준비만 확인할게요"라고 말하고 진행한다.
   - uv가 설치돼 있는지 버전을 확인한다. 없으면 README의 설치 명령을 안내한다
   - 코치가 대신 실행해도 되는지 묻고, `server/`에서 `uv run smoke_test.py`를 실행한다
   - 결과는 성공 여부만 알린다. 출력의 세부 목록과 calls.log는 1단계에서 처음 보여준다
5. **오늘의 MCP 서버 소개.** 다음 단계를 위해 `server/server.py`를 소개한다.
   - 이 파일이 오늘의 MCP 서버다
   - 설정: 초록스터디(자바·스프링·리액트 미션으로 공부하는 스터디)의 리드가 AI에게 미션 정보를 물어볼 수 있게 해주는 MCP 서버를 만든다고 가정한 연습용 서버다. 미션 이름은 실제, 나머지 데이터는 예시다
   - 80줄 남짓이니 다음 단계 전에 한 번 편하게 훑어보라고 권한다. 이해 안 돼도 괜찮다고 말한다
   - Desktop 답변에 따라 한 줄 덧붙인다 ("6단계에서 같이 써볼게요" 또는 "6단계는 건너뛰어도 괜찮아요")

## 완료 조건

- 학습자가 2번 질문에 답했다
- smoke test 마지막 줄에 "모두 정상입니다"가 나왔다

## 자주 헷갈리는 지점

- **uv 명령을 못 찾는다**: 설치 직후엔 터미널을 새로 열어야 잡힌다.
- **Python을 따로 설치해야 하나**: 아니다. uv가 필요한 Python을 받아온다. macOS 기본 python3는 3.9라서 mcp(3.10 이상 필요)를 pip로 직접 설치하면 실패하는데, uv를 쓰면 이 문제가 없다.
- **MCP와 그냥 API의 차이**: API는 사람이 문서를 읽고 호출하지만, MCP는 AI가 서버가 내준 설명을 읽고 스스로 호출할 수 있게 정한 약속이다. 3단계에서 직접 보게 된다고 연결한다.

## 하지 않는 것

- 첫 응답에 명령 실행 결과를 늘어놓지 않는다. 첫 응답은 1번 인사와 2번 질문까지만 한다.
- 2번 답을 받기 전에 3번 이후로 넘어가지 않는다.
- 이 단계에서는 "알게 된 것"을 짚지 않는다. 안내 단계다.
