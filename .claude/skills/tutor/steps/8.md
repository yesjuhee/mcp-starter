# 8. 학습 노트 만들기

## 목표

오늘 배운 것을 학습자의 노트 한 장(`notes/my-mcp-notes.md`)으로 정리하고 마무리한다.
설계 기준보다 **오늘 익힌 개념**과 **학습자의 질문**이 중심이다.

## 처음 나오는 용어

없음

## 해볼 것

1. `questions` 명령으로 오늘 기록한 학습자 질문을 불러온다.
2. 노트에 더 넣고 싶은 것이 있는지 한 번 묻는다. 없어도 된다.
3. 아래 구성으로 노트 초안을 만들어 보여준다. 학습자의 말과 실제로 본 장면을 최대한 그대로 쓴다.
4. 학습자가 고치고 싶은 곳을 반영한 뒤, 저장해도 되는지 묻고 `notes/my-mcp-notes.md`로 저장한다.
5. 정리 작업을 안내한다. 학습자가 원할 때만 한다.
   - Claude Code 연결 해제: `claude mcp remove cholog-hello -s local` (계속 실험하려면 두어도 된다)
   - Claude Desktop(6단계를 했다면): 백업한 설정으로 되돌리거나 cholog-hello 항목만 지운다
6. 수고했다고 인사하고 마친다.

## 노트 구성

```markdown
# 나의 MCP 학습 노트 (날짜)

## 오늘의 등장인물
학습자 / Claude Code / 모델 / MCP 서버가 각각 무슨 일을 하는지

## 세 가지 기능
5단계에서 함께 채운 비교표 (Tool, Resource, Prompt)

## 내가 직접 본 장면
3~6단계에서 본 것. calls.log 기록을 곁들여서

## 내가 했던 질문과 답
기록한 질문을 학습자의 말 그대로, 답은 한두 줄로

## 아직 궁금한 것
답이 확실하지 않았거나 더 알아보고 싶은 것

## 다음에 해볼 것
- 7단계에서 본 개선 포인트를 떠올리며 내 MCP 서버를 만든다면 무엇을 Tool로 둘지
- 레퍼런스: MCP Specification 2026-07-28 (https://modelcontextprotocol.io/specification/2026-07-28)
```

## 완료 조건

- `notes/my-mcp-notes.md`가 저장됐다

## 하지 않는 것

- 노트를 학습자에게 직접 쓰라고 하지 않는다. 코치가 초안을 만들고 학습자가 고친다.
- 학습자가 하지 않은 질문을 지어내지 않는다. 기록이 없으면 그 칸은 비워둔다.
