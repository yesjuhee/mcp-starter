# 6. Claude Desktop에서 써보기 (선택)

## 목표

같은 MCP 서버를 Claude Desktop에 연결해 3~5단계를 짧게 반복하고, Claude Code와 무엇이 다른지 본다.
Desktop의 모델은 server.py를 읽은 적이 없다.

Claude Desktop이 없거나 학습자가 원하지 않으면 `skip 6`을 실행하고 7단계로 간다.

## 처음 나오는 용어

없음

## 해볼 것

1. **설정 파일 확인.** macOS는 `~/Library/Application Support/Claude/claude_desktop_config.json`, Windows는 `%APPDATA%\Claude\claude_desktop_config.json`.
2. **uv 절대 경로 확인.** macOS는 `which uv`, Windows는 `where uv`. Desktop은 터미널의 실행 경로 설정을 물려받지 않아서 `"uv"`만 쓰면 못 찾을 수 있다.
3. **Desktop 완전히 종료.** 켜져 있으면 종료할 때 설정을 덮어써서 수정이 사라질 수 있다.
4. **백업 후 추가.** 설정 파일을 복사해두고, 기존 내용은 그대로 둔 채 `mcpServers`에 아래만 추가한다. 학습자 동의를 받고 진행한다. 같은 이름(`cholog-hello`)이 이미 있으면 덮어쓰지 말고 학습자에게 묻는다.

   ```json
   "cholog-hello": {
     "command": "<uv 절대 경로>",
     "args": ["run", "--directory", "<server 절대 경로>", "server.py"]
   }
   ```

5. Desktop을 켜고 학습자가 직접 해본 뒤 알려주게 한다. 코치는 Desktop 화면을 볼 수 없으니 학습자의 설명과 calls.log로 확인한다.
   - "초록스터디 자바 미션 뭐 있어요?" (허용 창이 뜨는지)
   - 첨부 없이 "초록스터디 전체 미션 목록 보여주세요" (어떤 길로 가져오는지)
   - 입력창의 `+` 메뉴에서 cholog-hello 항목을 찾아 Resource와 Prompt 써보기
6. calls.log를 함께 보고, Claude Code와의 차이를 코치가 표로 정리한다. Claude Code와 Desktop이 같은 calls.log에 기록한다는 점도 짚는다.

## 관찰 포인트

- 허용 창이 뜨는지
- 전체 목록을 물었을 때 Resource를 읽는지, Tool로 해결하는지
- Resource와 Prompt가 메뉴 어디에, 어떤 이름으로 보이는지
- 첨부와 Prompt 결과가 대화창에 어떤 모양으로 붙는지
- Prompt 입력 창에 무엇을 넣어야 하는지 안내가 있는지

## 완료 조건

- Desktop에서 세 기능을 써보고, Claude Code와의 차이를 표로 정리했다

## 자주 헷갈리는 지점

- **연결이 안 된다**: uv를 절대 경로로 썼는지, Desktop을 완전히 종료했다 켰는지, JSON 문법(쉼표, 중괄호)이 맞는지 본다.
- **같은 MCP 서버인데 왜 이렇게 다른가**: MCP는 MCP 서버가 무엇을 제공하는지를 정한다. 그걸 학습자와 모델에게 **어떻게 보여줄지는 AI 앱마다 다르다.**
- **Codex 같은 다른 AI 도구에도 붙나**: MCP 서버는 그대로 붙는다. 다만 Resource와 Prompt를 어떻게 보여주는지는 도구마다 다르다. 확인하지 않은 도구에 대해 단정하지 않는다.

## 하지 않는 것

- 학습자가 본 이상한 점(메뉴 이름, 첨부 모양, 입력 안내 등)의 원인을 먼저 말하지 않는다. 7단계에서 같이 본다.
